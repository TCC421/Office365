# Send Email Reminders for Entra App Credential Expiry

Set up Entra app credential expiry notifications using a PowerShell script to receive email alerts before app credentials expire and avoid disruptions to automation scripts.

***Sample Output***

The script retrieves all Microsoft Entra app registrations with credentials that are set to expire within the specified number of days. It then sends an email notification to the specified recipients, allowing them to renew the credentials before they expire. The script also exports a report of app registrations with expiring credentials. A sample output is shown in the screenshot below.
